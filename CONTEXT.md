# vue-python-demo System Architecture

A full-stack monorepo with Vue 3 frontend and FastAPI backend, deployed to Kubernetes (GKE). Supports AI/LLM RAG capabilities with vector database integration.

## Language

**User**:
A person who registers and uses the system.
_Avoid_: Account, customer, client

**Role**:
A permission level assigned to users (e.g., admin, user).
_Avoid_: Permission group, access level

**Agent**:
An AI assistant that handles queries and can invoke tools/functions.
_Avoid_: Model, LLM, chatbot

**SystemSetting**:
A key-value configuration stored in the database that affects system behavior.
_Avoid_: Config, setting, environment variable

**Document**:
A text document with 384-dimension embedding for vector similarity search.
_Avoid_: File, page, chunk

**RAG Query**:
A user question processed through retrieval-augmented generation.
_Avoid_: Search, query, prompt

**Module**:
A code-organization grouping related functionality (user, ai, admin, system, dashboard). Shared database, synchronous calls. Not a true DDD bounded context.
_Avoid_: Bounded context, component, package, service layer

**API Version**:
A versioned interface contract for API endpoints (v1 = legacy, v2 = current).
_Avoid_: Version, release, iteration

**Vector Store**:
Abstraction for embedding storage and similarity search. Implemented by ChromaDB (dev) or PGVector (prod).
_Avoid_: ChromaDB, PGVector, vector DB

**Embedding**:
384-dimension vector representation of text generated by all-MiniLM-L6-v2.
_Avoid_: Vector, encoding
